# Assets · imágenes

Coloca aquí los archivos con **exactamente estos nombres** y la plantilla los
tomará sin tocar código. Mientras no existan, `media-fallback.js` dibuja un
marcador de posición, así que la maqueta se puede revisar vacía.

| Archivo              | Uso                          | Formato sugerido      |
|----------------------|------------------------------|-----------------------|
| `hero-poster.jpg`    | Póster del vídeo del hero    | 1920×1080, < 300 kB   |
| `project-01.jpg`     | Cartera · pieza vertical     | 1200×1600             |
| `project-02.jpg`     | Cartera · pieza vertical     | 1200×1500             |
| `project-03.jpg`     | Cartera · pieza apaisada     | 2000×1125             |
| `project-04.jpg`     | Cartera · pieza horizontal   | 1600×1200             |
| `project-05.jpg`     | Cartera · pieza vertical     | 1200×1600             |
| `service-01…06.jpg`  | Vista previa de servicios    | 800×1000              |
| `testimonial-bg.jpg` | Fondo del testimonio         | 2000×1200             |
| `og-cover.jpg`       | Miniatura para redes         | 1200×630              |

**Recomendación**: exporta también `.webp` y añade un `<picture>` en el HTML si
buscas la máxima puntuación en Lighthouse.

## Vídeo

`../video/hero.mp4` — H.264, sin audio, 8–12 s en bucle, < 6 MB.
Añade `../video/hero.webm` (VP9) para reducir peso en Chrome/Firefox.
